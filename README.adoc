For a long time, I was advert to coding assistants. I didn't see any benefit: it was faster for me to write code, than to let them generate crap, and fix it afterwards. Then, around summer 2025, something changed. At home, I used Claude Code for better and better results. At work, GitHub Copilot was not as good, but it was still producing acceptable results.
